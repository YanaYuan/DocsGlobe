使用前，请了解这些边界

01 / 来源

核对页面，不等于核验执业

医生介绍根据医院、高校及研究机构的公开资料整理，原始出处可展开查看；邮箱另附直接来源。核对日期不代表原站刚更新，也不证明当前执业、出诊或邮箱有效。

02 / 评价

暂不收录患者评价

首版不抓取社交帖子、不生成评分、不收集患者病历。“未收录”不是“没有评价”，也不是零分。

03 / 联系

学术邮箱不等于挂号渠道

展示已公开的学术邮箱及原始出处，未测试收信或回复，不保证接受患者咨询。不要直接发送病历或身份证信息；预约、出诊及急诊请走正规就医渠道，不收录私人手机或微信。

本项目仅作信息导航，不提供诊断或医疗建议。专业方向匹配不是治疗建议；是否适合就诊需由医疗专业人员评估。急症请及时就医或拨打 120。

资料过期、错误或需要移除时怎么办？

本地使用者请联系项目维护者；发布到 GitHub 后，可在该仓库提交 Issue，注明医生记录 ID、待更正字段与官方证据链接。请勿上传病历或患者身份信息。当前原型尚未提供公开在线提交服务。

代码与来源内容的授权分开处理；请查看仓库说明后再使用或再分发数据。
